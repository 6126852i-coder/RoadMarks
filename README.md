# RoadMark — запись дорог и оценка покрытия

Android-приложение: по GPS рисует на карте трек (в том числе дороги, которых нет на карте)
и раскрашивает его по состоянию покрытия:

- 🟢 зелёный — хорошая дорога
- 🟡 жёлтый — средняя
- 🔴 красный — плохая
- ⚪ серый — нет оценки (стоянка, скорость ниже порога)

Оценка автоматическая: телефон в держателе меряет тряску акселерометром
между точками GPS. Кнопками «Плохо / Средне / Хорошо» можно размечать участки вручную.

## Как собрать APK

1. Установите **Android Studio** (бесплатно, developer.android.com/studio).
2. Распакуйте архив и откройте папку `RoadMark` через **File → Open**.
3. Дождитесь синхронизации Gradle (первый раз 5–10 минут, нужен интернет).
4. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Перекиньте его на телефон и установите (разрешите «установку из неизвестных источников»).

Или подключите телефон по USB с включённой отладкой и нажмите ▶ Run.

## Как пользоваться

1. Закрепите телефон в держателе (жёстко, не в кармане и не на сиденье).
2. Нажмите **Начать запись** и разрешите доступ к местоположению.
3. Поезжайте. Каждые ~15 м на карту добавляется цветной участок.
4. **Остановить запись** — поездка сохраняется в телефоне.
5. Меню ☰ — список поездок, показать/скрыть, удалить, **Экспорт GeoJSON**
   (файл появится в «Загрузки/RoadMark», его открывают QGIS, geojson.io, JOSM).
6. ⚙ — пороги тряски. Проедьте по заведомо хорошему асфальту, посмотрите
   значение «Тряска» вверху и поставьте границу «хорошая/средняя» чуть выше.

Кнопка **Демо** показывает имитацию поездки — можно посмотреть работу без выезда.

## Ограничения этой версии

- Экран должен быть включён во время записи (приложение само не даёт ему погаснуть).
  Запись в фоне с выключенным экраном требует отдельного сервиса — это следующий шаг.
- Нужен интернет для подложки карты OpenStreetMap. Без интернета трек всё равно
  пишется и рисуется на схеме, а карта появится, когда связь вернётся.
- Тряска зависит от машины, шин и держателя — пороги лучше подстроить один раз под себя.

## Структура

- `app/src/main/assets/index.html` — всё приложение (карта, запись, оценка, экспорт).
  Этот же файл работает в Chrome на телефоне, если выложить его на любой https-хостинг
  (например, GitHub Pages).
- `app/src/main/java/uz/roadmark/MainActivity.kt` — обёртка: WebView, разрешения GPS,
  сохранение файлов, экран не гаснет при записи.
